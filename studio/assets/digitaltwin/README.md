# Molten-Salt Blanket Digital Twin — Laptop Assets

Run on an AMD Instinct MI355X (gfx950) cluster. All data is from the lux run (seed 2026).

## Files

| File | Description |
|---|---|
| `portal.html` | **Start here** — self-contained, double-click to open. Tabs: Overview / Presentation / Live Twin. No server needed. |
| `msb_twin_demo.mp4` | Demo video (1:43, 1920×1080); not tracked in git (12 MB), regenerate or obtain separately |
| `MSB_DigitalTwin_lux.html` | 9-slide presentation (needs `deck_data.js` + `AMD-Logo.png` in same folder) |
| `dashboard.html` | Live twin dashboard (needs `twin_data.js` + `dashboard.js` + `AMD-Logo.png`) |
| `MSB_DigitalTwin_radha.html` | Presentation from an earlier run on a different cluster, for comparison |

## Quick start

Double-click `portal.html` — it's fully self-contained (logo, all data, all JS inlined).
