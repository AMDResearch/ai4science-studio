# Protein folding

This domain holds recipes for **protein structure**, **folding**, **protein language models**, and related open models on Hugging Face.

## Model directories

All models live under [`models/`](models/):

- [`models/README.md`](models/README.md) — slug naming and how to add a model.

Layout reference: [`../_template/`](../_template/).

## Recipes

Per-model recipes live in `models/<model-slug>/recipes/`. Index: [`../recipes/README.md`](../recipes/README.md).

## Contributing

1. Create `models/<model-slug>/README.md` with HF id, license, and citations.
2. Add recipes under `models/<model-slug>/recipes/`.
3. Respect **biological data and model licenses**; state any non-commercial or research-only restrictions clearly.
